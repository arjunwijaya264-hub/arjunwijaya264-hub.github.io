# Arjun Wijaya — Portfolio Website

Website portofolio HTML statis yang dibuat dari CV terbaru dan PDF portfolio.

## Isi
- `index.html` — halaman portfolio utama
- `assets/` — foto portfolio dan favicon

## Menjalankan lokal
Klik dua kali `index.html` untuk membukanya di browser.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `arjun-wijaya-portfolio`.
2. Upload **isi folder ini** (`index.html` + folder `assets`).
3. Buka **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. GitHub akan memberikan alamat website Pages.

## Deploy ke Netlify
1. Masuk ke Netlify.
2. Pilih opsi untuk menambahkan/deploy site secara manual.
3. Upload folder `arjun-wijaya-portfolio`.
4. Website akan mendapat alamat `*.netlify.app` dan dapat disambungkan ke domain sendiri.

## Catatan privasi
Nomor telepon, email, dan LinkedIn sengaja tidak dimasukkan ke website. LinkedIn yang tercantum di CV dan Instagram yang diberikan secara eksplisit digunakan sebagai tautan sosial.
